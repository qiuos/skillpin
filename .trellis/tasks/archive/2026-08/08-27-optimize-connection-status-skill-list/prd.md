# 优化连接状态与技能列表布局

## Goal

增强顶部本地连接状态的可识别性与现有羊皮纸/墨金视觉语言的一致性；调整技能工作台的左右信息密度，使技能目录可展示更多有用信息并占据更大空间，同时适度压缩详情区域。

## What I already know

* 顶部当前连接状态仅由小圆点和文字组成，视觉存在感偏弱；结束会话按钮仍使用全局默认字号，未跟随工作台较大的界面字号。
* 技能工作台当前左右栏比例为约 `0.9 : 1.4`，详情栏大于列表栏。
* 列表项目前显示：技能名、两行摘要、启用状态、启用/移除操作；其来源、候选数量、解析备注等信息未在主列表直接展示。
* 关键实现位置：`packages/web/src/app/app.tsx`、`packages/web/src/features/catalog/skills-workbench-page.tsx`、`packages/web/src/styles.css`。

## Requirements

* 将顶部连接状态改为更明显、且融入现有复古羊皮纸/金色描边/酒红强调风格的状态组件；不同连接状态仍需保留清晰区分。
* 调整“结束 SkillPin”按钮的文字大小，使其与顶部导航及当前工作台的放大字号体系协调。
* 将技能工作台的横向空间更多分配给技能列表，并相应缩小详情栏。
* 在不干扰快速选择和启用/移除操作的前提下，丰富每条技能列表项的可见信息；优先利用已有数据（例如来源、候选数、异常/解析备注）。
* 保持列表虚拟滚动、详情查看、筛选与启用/移除行为不变，并维持窄屏下的现有单栏适配。
* 移除技能详情中的冗余提示文案“在列表中点击启用或移除，立即应用变更。”。

## Acceptance Criteria

* [ ] “已连接”状态在顶栏中能一眼识别，视觉语言与应用现有风格一致；连接中、重连、结束中、已断开和错误状态仍能区分。
* [ ] “结束 SkillPin”按钮的文字大小得到调整，且不会破坏顶栏布局或可访问名称。
* [ ] 桌面宽度下，技能列表栏宽于详情栏。
* [ ] 每个列表项除名称、摘要和操作外，额外呈现至少一种现有可用的上下文信息（如来源、候选数或异常提示）。
* [ ] 筛选、选中、滚动、详情读取、启用和移除的现有行为保持正常。

## Definition of Done

* 相关单元/端到端测试按影响范围更新。
* lint、typecheck 与相关测试通过。
* 窄屏布局及键盘/语义可访问性不回退。

## Out of Scope

* 不改变会话连接和结束会话的后端逻辑。
* 不新增技能元数据接口或修改技能文件格式。
* 不重做技能详情 Markdown 阅读体验，除移除冗余操作提示文案外。

## Technical Notes

* 顶栏标记位于 `AppShell`，连接状态通过 `connectionCopy()` 和 `status-dot--<state>` 映射。
* 工作台列表是虚拟列表，单行估计高度当前为 224px，相关 CSS 为 `.skills-columns`、`.skill-row` 等。
* 当前适配策略在 `packages/web/src/styles.css` 的媒体查询中处理，实施时需保留。

## Open Questions

* 无阻塞问题：默认以“突出状态徽章 + 复古印章/边框”方式增强顶部状态，并在列表增加来源/候选/异常等现有元信息；待用户确认后实施。

## Decision (ADR-lite)

**Context**：顶部连接反馈较弱，技能目录的空间和元信息不足；现有数据模型已经提供来源、候选和解析状态，无需增加接口。

**Decision**：采用突出状态徽章（保留状态文字并增加边框/底色/状态标识）的方式改造顶栏；将桌面工作台调整为列表优先的双栏比例，并在技能条目中加入来源、候选数量与解析备注等元信息。

**Consequences**：需要同步调整虚拟列表行高估计、相应样式和覆盖到顶栏与工作台的端到端测试；不涉及后端与数据协议。
