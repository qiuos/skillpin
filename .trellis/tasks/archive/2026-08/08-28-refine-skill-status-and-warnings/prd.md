# 优化技能页状态栏与告警可见性

## Goal

修复技能工作台的视觉一致性和可用性问题：统一右上角连接状态与结束按钮的高度；提高“技能源”及“添加技能源”弹窗的文字可读性；让新增技能源后的扫描告警可被查看，并在重新扫描无异常时自然清除。

## Requirements

* 统一右上角连接状态与“结束 SkillPin”按钮的视觉高度及垂直对齐。
* 按既有技能源页面规格，调大并统一“技能源”页面及“添加技能源”弹窗中关键文字的字号，提高可读性。
* 当技能源存在扫描警告时，“存在警告”标签应可点击。
* 点击告警标签后打开弹窗，列出该技能源返回的所有具体告警原因。
* 告警弹窗须明确提示：这些告警**不影响正常使用**。
* 用户重新扫描后，列表使用最新扫描结果：若没有警告，不再显示告警标签；若仍有警告，展示更新后的原因。

## Acceptance Criteria

* [x] 连接状态控件与结束按钮在同一行具有一致的高度和垂直对齐。
* [x] 技能源页面标题、名称、路径、状态、工具栏文字及行内操作符合既有 28px/24px 字体规格；添加弹窗的标题、标签、输入、说明、按钮和反馈文字均不再显得偏小且保持一致。
* [x] 技能源列表的“存在警告”标签可通过鼠标和键盘触发。
* [x] 触发后显示告警弹窗，含“告警不影响正常使用”的明确说明，以及全部告警原因。
* [x] 点击重新扫描后，若服务端返回空警告数组，告警标签与对应原因不再显示；若仍有告警，则弹窗呈现最新内容。
* [x] 相关前端测试更新，lint、类型检查和现有测试通过。

## Definition of Done

* Tests added/updated where appropriate.
* Lint / typecheck / CI green.
* Docs/notes updated if behavior changes.
* Rollout/rollback considered if risky.

## Technical Approach

* 在应用顶栏复用按钮尺寸令牌/样式，使会话状态和结束操作使用一致的高度。
* 在 `styles.css` 中按技能源既有 28px/24px 可读性契约调整页面与对话框相关排版，避免影响技能工作台的独立密度设计。
* 利用已存在于 `LocalSourceSummary.scan.warnings` 的告警数组；扩展 `SourceHealth`/技能源列表状态，使用可访问的按钮打开通用 `Dialog`，而不新增后端接口或改变扫描逻辑。
* 重新扫描已通过 `SourceProvider` 刷新对应 source 摘要；界面从刷新后的 `scan.warnings` 派生显示状态，避免保存陈旧告警。

## Decision (ADR-lite)

**Context**：技能源扫描已经返回结构化告警，但列表只有不可交互的“存在警告”标签，用户无法判断是否需要处理。

**Decision**：将标签改为可触发控件；点击后以模态弹窗展示全部原因，并明确说明告警不影响正常使用。

**Consequences**：不占用列表额外空间，告警信息可完整阅读且键盘可访问；继续以服务端最新扫描摘要为单一事实来源，重新扫描成功时自动清除已消失的告警。

## Out of Scope

* 不改变技能源新增、目录校验或扫描的业务逻辑。
* 不将告警升级为阻塞性错误，也不新增单条告警的忽略/确认状态。
* 不重新设计整个技能工作台。
